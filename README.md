## 2. 중간고사: 새로 추가한 기능 — 냉장고 재료로 메뉴 찾기

### 2-1. 한두 문장 설명

7주차 흐름의 **3단계(메뉴 선택) 중간**에 "냉장고 재료로 메뉴 찾기" 경로를 추가했습니다. 자취생이 가진 재료를 입력하면 그 재료로 만들 수 있는 메뉴를 부족한 재료가 적은 순서로 보여 주고, 메뉴를 계획에 담으면 **부족한 재료만 모은 장보기 목록**이 4단계 확인 화면과 5단계 완료 화면에 반영됩니다.

### 2-2. 사용자 목표와의 연결

- 사용자 목표는 "예산 안에서 일주일 식단 짜기"인데, 7주차에는 냉장고에 이미 있는 재료를 고려하지 못해 같은 재료를 또 사는 문제가 있었습니다.
- 새 기능은 **메뉴를 고르는 바로 그 지점(3단계)**에 연결되어, 가진 재료를 먼저 쓰는 메뉴를 고르게 하고 장보기 비용과 중복 구매를 줄입니다.
- 결과는 다음 단계(확인·완료)의 장보기 목록에 이어져, 흐름의 끝에서 사용자가 바로 장을 볼 수 있습니다.

### 2-3. 새 기능의 흐름

```
[3단계 메뉴 선택]
   └ "🧊 냉장고 재료로 메뉴 찾기" 클릭
        └ 재료 추가(입력·Enter·자주 쓰는 재료 버튼) ─ 칩 ✕로 빼기 / 재료 모두 지우기
             └ "메뉴 찾기" 클릭
                  ├ 결과 있음 → 메뉴별 가진 재료·부족한 재료·1끼 예산 배지 → "계획에 담기"
                  │              → 3단계 체크·예산 막대 갱신 → 4단계 장보기 목록 → 5단계 장보기 목록
                  ├ 결과 없음 → 안내 + "전체 메뉴에서 고르기" / 재료 더 추가
                  └ 찾기 취소 → 패널 닫고 3단계 목록으로 (담은 메뉴·입력한 재료 유지)
```

### 2-4. 사용자 행동 · 확인할 조건 · 반응 · 다음 행동

| 사용자 행동 | 확인할 조건 | 성공 반응 | 다른 분기의 반응 (오류·결과 없음·취소) | 다음 행동 |
| --- | --- | --- | --- | --- |
| "냉장고 재료로 메뉴 찾기" 클릭 | - | 찾기 패널 열림, 입력창에 포커스 | - | 재료 입력 |
| 재료 입력 후 "재료 추가" 또는 Enter, 자주 쓰는 재료 버튼 클릭 | ① 빈 값 아님 ② 한글·영문 1~10자(숫자·기호·띄어쓰기 불가) ③ 중복 아님(영문은 대소문자 구분 없이) ④ 8개 이하 | 파란 칩 추가, "(n/8) 추가했어요" 안내, 입력창 비움, 찾기 버튼에 재료 수 표시, 이미 넣은 자주 쓰는 재료 버튼은 비활성화 | ① "재료 이름을 입력해 주세요. 예: 계란" ② "숫자·기호·띄어쓰기 없이 한글이나 영문 1~10자로" ③ "이미 추가한 재료예요" ④ "최대 8개, ✕로 뺀 뒤 추가" — 입력창 빨간 테두리 | 재료 수정 후 다시 추가 |
| 칩의 ✕ 클릭 | - | 해당 재료 제거, 입력창으로 포커스 이동, 결과가 열려 있으면 즉시 다시 계산 | 마지막 재료를 빼면 결과를 지우고 "다시 찾으려면 재료를 추가" 안내 | 재료 추가 / 메뉴 찾기 |
| "메뉴 찾기" 클릭 | 재료 1개 이상 | 가진 재료가 1개 이상 들어간 메뉴를 부족한 재료가 적은 순으로 표시(결과 위치로 자동 스크롤), 메뉴마다 가진 재료 수·부족한 재료·"1끼 예산 안/초과" 배지 | 재료 0개: "재료를 1개 이상 추가한 뒤" 오류(빨강) / **결과 없음**: "○○(으)로 만들 수 있는 메뉴가 아직 없어요" 빈 상태 + 재료 이름 확인 안내(파랑) + "전체 메뉴에서 고르기" 버튼 | 계획에 담기 / 재료 추가 / 전체 메뉴로 |
| "계획에 담기" 클릭 | ① 이미 담긴 메뉴 아님 ② 끼니 수 미만 | 버튼이 "담김 ✓"로 바뀌고 초록 테두리, 3단계 목록 체크·예산 막대 갱신, 안내 문구로 포커스 이동 | ② 끼니 수를 채웠으면 "하나를 체크 해제한 뒤 다시 담아" 오류 / 담은 뒤 예산 초과면 "예산을 ○원 넘었어요" 경고(3단계 다음 버튼도 차단) | 다른 메뉴 담기 / 다음 단계 |
| 3단계 목록에서 담은 메뉴 체크 해제 | - | 찾기 결과의 버튼이 다시 "계획에 담기"로 돌아옴 | - | 다시 담기 |
| "찾기 취소" 클릭 | - | 패널 닫힘, "담은 메뉴와 입력한 재료는 그대로" 안내 | - | 전체 메뉴에서 선택 / 다시 열기(재료 유지) |
| "재료 모두 지우기" 클릭 | - | 재료·결과만 초기화(담은 메뉴는 유지) | - | 새 재료 입력 |
| 3단계 "다음" → 4단계 | 7주차 조건(1개 이상·끼니 수 이하·예산 이하) | 확인 화면에 **장보기 목록**(냉장고 재료 제외 개수 표시)과 "재료 수정" 버튼 | 냉장고 재료로 모두 만들 수 있으면 "장 볼 필요가 없어요" | 확정 / 재료 수정 |
| 확인 화면의 "재료 수정" 클릭 | - | 3단계로 이동하면서 냉장고 재료 찾기 패널을 바로 열어 재료 칩 표시 | - | 재료 추가·빼기 후 다시 확인 |
| "이대로 계획 확정" | - | 완료 화면에 장보기 목록을 칩으로 표시하고 어떤 재료를 뺐는지 안내 | 재료를 입력하지 않았으면 "필요한 재료를 모두 담았어요" 안내 | 처음부터 다시 |
| "이전"으로 2단계 갔다가 돌아오기 | 2단계에서 끼니 수·예산을 바꿨는지 | 입력한 냉장고 재료 유지, 찾기 결과의 "담김" 표시와 1끼 예산 배지를 새 값으로 다시 계산 | 끼니 수를 줄이면 넘치는 메뉴는 빠지고 그 메뉴의 버튼이 다시 "계획에 담기"로 돌아옴 | 계속 진행 |
| "처음부터 다시 만들기" | - | 냉장고 재료·결과·패널·안내 문구까지 모두 초기화 | - | 1단계부터 다시 |

| 7주차 | 일주일 식단 만들기 5단계 흐름(목표 → 예산·끼니 → 메뉴 → 확인 → 완료) |

### 7주차 사용자 흐름

```
[1. 목표 선택] → [2. 닉네임·주간 식비·끼니 수] → [3. 메뉴 선택] → [4. 확인] → [5. 완료]
                    ↑ 이전(값 유지)              ↑ 이전(체크 유지)   │ 수정 버튼으로 1·2·3단계 이동
                                                                    └ 확정 → 완료 → 처음부터 다시(초기화)
```

### 7주차 인터랙션 시나리오 (행동 → 이벤트 → 조건 → 화면 반응 → 다음 상태)

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 목표 없이 "다음" | click | 선택된 목표 없음 | "식단 목표를 하나 골라 주세요" | 1단계 유지 |
| 닉네임·예산·끼니 오류로 "다음" | click | 2자 미만 / 10,000~200,000원 밖 / 끼니 미선택 | 해당 입력창 강조와 수정 안내, 포커스 이동 | 2단계 유지 |
| 정상 입력 후 "다음" | click | 모두 통과 | 목표에 맞는 메뉴를 배지와 함께 위로 정렬 | 3단계 |
| 메뉴 체크 | change | - | 선택 개수·예상 비용·남는 예산 즉시 갱신 | 3단계 |
| 메뉴 오류로 "다음" | click | 0개 / 끼니 수 초과 / 예산 초과 | 몇 개를 빼야 하는지, 얼마나 넘었는지 안내 | 3단계 유지 |
| 정상 선택 후 "다음" | click | 통과 | 요약과 단계별 수정 버튼 | 4단계 |
| "이전"·"수정" | click | - | 해당 단계로 이동, 값 유지 | 1~3단계 |
| "이대로 계획 확정" | click | - | 닉네임이 들어간 완료 문구 | 5단계 |
| "처음부터 다시" | click | - | 모든 입력·선택·오류·진행 표시 초기화 | 1단계 |
